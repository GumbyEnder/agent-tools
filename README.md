# agent-tools

General-purpose agent skills. Each skill is a directory with a `SKILL.md` file, following the [Agent Skills](https://agentskills.io/specification) layout. Copy a skill folder into the skills directory your agent reads.

## Skills

| Skill | What it is for |
| --- | --- |
| [loops-and-graphs](skills/loops-and-graphs/SKILL.md) | Design and run multi-agent work so a human approves only the final irreversible step. |
